Some details:
Postgres: use the pgvector/pgvector image, so the same database handles history, memory, and vector search.
Langfuse: self-hosting it is heavier than the rest of your stack (it needs ClickHouse, Redis, and object storage). For a proof of concept, its free cloud tier is simpler, as long as you test with non-sensitive data. Otherwise, run their own compose file next to yours.
Tools: start them as plain functions inside tools/. Once that works, move them behind an mcp_servers/ folder. It’s a small refactor if each tool already has a clean typed signature.
uv workspace: this lets backend depend on chatbot as a local package, with one lockfile for the repo.

A good first milestone: docker compose up gives you a Streamlit chat with session history and a single tool working, with every turn visible as a trace in Langfuse.
